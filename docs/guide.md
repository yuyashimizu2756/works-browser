# 使い方ガイド

画面の操作と設定の説明です。設計の背景は [design.md](./design.md)、索引と走査は
[scan-design.md](./scan-design.md)、サムネイルは [thumb-design.md](./thumb-design.md) を参照してください。

## 1. ルートを追加する

1. 右上の **`＋ルート`**（または `Ctrl+O`）を押します。
2. フォルダを選ぶか、ウィンドウへ**ドラッグ&ドロップ**します。
3. 「深さ」を選びます。作品の単位になります。

| 深さ | 作品のまとまり |
|---|---|
| 1 階層 | 直下フォルダ = 1 作品（例: `作品A\001.png`）|
| 2 階層 | 2 階層目まで = 1 作品（例: `作品A\シーン1\001.png`）|
| フラット | ルート直下のファイルを 1 作品として扱う |

- 走査は追加直後に始まり、進捗はヘッダーに出ます。`Esc` で中止できます。
- 同じ実体（junction / ハードリンク）を別ルートで追加した場合は「重複 #1」と表示され、
  二重索引しません。
- 走査対象外: `node_modules`、`__pycache__`、`.` 始まりのフォルダ（設定で変更可）。

## 2. 画面と表示モード

| モード | キー | 内容 |
|---|---|---|
| 作品 | `Alt+1` | フォルダ単位のカード。カバーは動画優先 |
| ファイル | `Alt+2` | ファイル単位の一覧（6 万件でも仮想スクロール）|
| タイムライン | `Alt+3` / `Ctrl+Shift+T` | 更新日ごとにまとめた俯瞰。日付見出しは固定 |

- サムネイルは**起動ごとに非表示**から始まります（表示状態は保存しません）。ツールバーの **`サムネ`**（または `Ctrl+Shift+H`）で表示。
- 個別に見たいときは、カードにホバーして出る**目アイコン**（サムネ非表示時のみ）を押します。
  これは一時的で、全体トグルを切り替えるとリセットされます。
- 作品詳細から戻ると、**ルート・検索語・並び順などの絞り込みが復元**されます
  （ライトボックスを開いてから 2 回戻った場合も同じです）。

## 3. 検索と絞り込み

- `/` で検索欄へフォーカス。タイトル・パスを部分一致で検索します。
- **フィルタ**（ポップオーバー）: 種類 / ルート / タグ / 評価 / お気に入り / 生成情報も検索。
- **並び**: 更新日・追加日・名前・サイズ・ファイル数。`↑↓` で昇順/降順。
- **生成情報も検索**: プロンプト・モデル名・LoRA などを対象にする（設定で索引が必要）。
- **スマートフォルダ**: 現在の条件を名前付きで保存し、サイドバーから呼び出します。

## 4. 作品詳細とライトボックス

- カードをクリックすると詳細へ。題名・メタ・評価の 3 層、右上に「開く」「フォルダ」「⋯」。
- ライトボックスでは `←` / `→` で移動、`Space` で再生/停止、`F` で全画面、`0` で原寸。
- 動画は**既定ミュート・音量 0**。解除は明示操作のみです。解除したとき音量が 0 なら
  60% まで上がります。再生中の解除では、音声出力を再初期化します（一瞬止まって再開）。
- ホバーで 5 秒の無音プレビュー（設定で無効化可）。

ライトボックスを閉じずに、作品単位の操作ができます。

| 操作 | 場所 | キー |
|---|---|---|
| お気に入り | 上部バーのハート | `Shift+F`（`F` は全画面のまま）|
| 5 段階評価 | 上部バーの星 | `1`〜`5` / 未評価は `Shift+0`（`0` は原寸 / 先頭）|
| タグ編集 | 上部バーのタグ | `T`（既存のタグダイアログ）|
| 生成情報パネル | 上部バーの情報 | `I` でトグル |
| スライドショー | 下部バー | `S`（画像は 3 秒送り、動画は再生完了で次へ）|
| フォルダで開く / パスをコピー / ゴミ箱へ | 上部バーの `⋯` | 削除は `Delete`（確認 + Undo）|

- 評価・お気に入りは**作品単位**で、詳細ヘッダや一覧のフィルタと同期します。
- 評価・お気に入りは、その作品のマークを**読み込み終わるまで操作できません**（読み込み中は
  グレー表示とツールチップ）。保存に失敗したときは操作前に戻り、上部に理由を出します。
  キーを押しっぱなしにしても連打しません。
- 上部の短い通知（音声・コピー・保存失敗など）は **1 行のキュー**です。同時に起きても
  高さは変わりません。
- 動画の下部バーには `Space 再生 / ←→ ±5秒 / Shift+←→ 前後 / Esc 閉じる` の案内が
  出ます（画像はズーム案内のまま）。スライドショーのボタンは下部バーに 1 つだけです。
- 幅を狭くすると、上部の位置表示（`2 / 24`）だけを残し、サイズと日付は省略します。
- `⋯` の「パスをコピー」はルートの実パスとファイルの相対パスを繋いだ絶対パスです。
- `Esc` は「タグ / 確認ダイアログ → `⋯` メニュー → ライトボックス → 詳細」の順に 1 段ずつ閉じます。

## 5. 選択・削除・移動

- 選択は**チェックボックス**のみ（カードのクリックは開く）。`Ctrl` / `Shift` / 矩形ドラッグにも対応。
- `Delete` でゴミ箱へ（確認あり）。`Shift+Delete` は完全削除（元に戻せません）。
- 削除後 5 秒は **Undo** できます。
- 作品はサイドバーのルートへ**ドラッグ&ドロップで移動**できます（同一ボリュームは即時、別ボリュームはコピー）。

## 6. タグ・評価・お気に入り

- 作品詳細のタグ欄から作成・付与。タグは索引 DB に保存され、再走査でも残ります。
- 1〜5 の評価とお気に入りは作品単位。一覧では `1`〜`5` / `0` / `F`、
  ライトボックスでは `1`〜`5` / `Shift+0` / `Shift+F` で付けられます。
- 生成情報から**タグ候補**を提示します（頻出語、表記ゆれ統合、長すぎる語は除外）。

## 7. 重複・類似の整理

ヘッダーの **`重複整理`** から、完全一致（SHA-1）と類似（dHash 64bit）をグループ表示します。

1. 初回は「解析する」を押します（バックグラウンド、進捗表示、中止可）。
2. グループごとに「残す 1 枚」を提案（画素数 → バイト数 → 新しい順）。
3. サムネイルをクリックすると別の 1 枚をキーパーに指定できます。
4. 「他をゴミ箱へ」で、キーパー以外を削除フローへ（Undo あり）。

## 8. 比較と差分

- 2〜4 枚を選択して「比較」。ズームとパンを同期します。
- 2 枚のときは「差分」タブで、プロンプトの単語差分・LoRA の集合差・seed 違いバッジを表示します。

## 9. ComfyUI 連携

設定で ComfyUI の URL（既定 `http://127.0.0.1:8188`）と workflows フォルダを指定します。

- 生成情報パネルの **「ComfyUI へ」**:
  - `workflow`（UI 形式）があれば workflows フォルダへ保存し、`?workflow=` で開く
  - `prompt`（API 形式）のみならクリップボードへコピー
- **「この設定で再実行」** は `POST /prompt` でキューへ投入します（確認ダイアログあり）。

## 10. プライバシーシールド

- `Ctrl+Shift+P` で画面を隠します。解除はホットキーを**長押し**（既定 1 秒）。
- 見た目は「ファイル一覧風」と「無地」から選べます。起動時から隠す設定もあります。

## 11. 設定

設定画面（ヘッダーの歯車）で、除外パターン・ffmpeg・サムネ品質/上限・動作などを変更できます。
`config.json` の全項目は [settings-design.md](./settings-design.md) を参照してください。

主なキー:

| キー | 既定 | 説明 |
|---|---|---|
| `view_mode` | `works` | `works` / `files` / `timeline` |
| `thumbnails_visible` | `false` | 互換用の旧キー。起動時の表示には使わない（保存もしない）|
| `shield_hotkey` | `Ctrl+Shift+P` | シールドのホットキー |
| `exclude_patterns` | `["node_modules","__pycache__",".*"]` | 走査の除外 |
| `thumb_quality` | `75` | WebP 品質 |
| `thumb_cache_limit_mb` | `512` | キャッシュ上限（0 = 無制限）|
| `comfy_url` | `http://127.0.0.1:8188` | ComfyUI の接続先 |

## 12. データの場所

| 種類 | 場所 |
|---|---|
| 索引 DB（リリース）| `%APPDATA%\works-browser\index.db` |
| 索引 DB（開発）| `<repo>\.cache\index.db` |
| サムネイル | `%LOCALAPPDATA%\works-browser\thumbs\` |
| 設定 | `%APPDATA%\works-browser\config.json` |

環境変数 `WORKS_BROWSER_DB` / `WORKS_BROWSER_THUMBS_DIR` で上書きできます。

## 13. キーボード

`?` で一覧を表示します（ライトボックス表示中も可。`Esc` は「ヘルプ → ライトボックス → 詳細」の順）。

| 操作 | キー |
|---|---|
| フォーカス移動 | `J` / `K` |
| 評価 | `1`〜`5` / `0` |
| お気に入り | `F` |
| 開く | `Enter` |
| 検索 | `/` |
| 削除 | `Delete` / `Shift+Delete` |
| ルート絞り込み | `Ctrl+1`〜`Ctrl+9` / `Ctrl+0` |
| 表示モード | `Alt+1` / `Alt+2` / `Alt+3` |
| サムネ表示 | `Ctrl+Shift+H` |
| 戻る / 進む | `Alt+←` / `Alt+→`（マウスの戻る/進むも可）|
| ライトボックス: お気に入り | `Shift+F` |
| ライトボックス: 評価 / 未評価 | `1`〜`5` / `Shift+0` |
| ライトボックス: タグ / 生成情報 | `T` / `I` |
| ライトボックス: スライドショー / ゴミ箱へ | `S` / `Delete` |

## 14. デモ / ベンチモード（開発用）

`?bench=24&demo=1` を付けて起動すると、合成データとサンプル画像で画面を確認できます
（開発・スクリーンショット用。通常の利用では使いません）。

- デモ / ベンチモードは**実 DB に保存しません**。お気に入り・評価・タグは固定の
  サンプル表示になり、保存系のボタンは無効になります（ツールチップで案内が出ます）。
- 開封回数の記録やタグの読み書きも行わないため、実在する作品のデータは変わりません。
- ライトボックスのお気に入り・評価・タグも同じく操作できません。
