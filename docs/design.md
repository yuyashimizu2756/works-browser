# デザイン仕様（Gallery minimal / #96・#98）

ライブラリのクローム（ヘッダー・ツールバー・サイドバー）と作品グリッドを
**Gallery minimal** に揃えるための仕様です。作品（サムネイル）が主役で、操作系は静かに、
状態だけアクセントで示します。テーマは**ダークのみ**。

値の正は `src/index.css` の `:root` に置いた CSS 変数 1 箇所です。画面側は `var(--xxx)` か、
対応する Tailwind クラスだけを使います。

## トークン

### 余白

| 名前 | 値 | 主な用途 |
|---|---|---|
| `--space-1` | 4px | アイコンと文字の間 |
| `--space-2` | 8px | ボタン内の間隔、チップ間 |
| `--space-3` | 12px | 行内の余白 |
| `--space-4` | 16px | ツールバーの左右、カード間 |
| `--space-6` | 24px | 画面の左右、ヘッダーの左右 |
| `--space-8` | 32px | セクション間 |
| `--space-12` | 48px | 大きな区切り |

Tailwind の既定スケール（`p-1` = 4px … `p-12` = 48px）と一致します。

### 角丸

| 名前 | 値 | 用途 |
|---|---|---|
| `--radius-control` | 8px | ボタン、入力、セグメント |
| `--radius-card` | 12px | 作品カード、ファイルタイル |
| `--radius-panel` | 16px | ポップオーバー、パネル |

### 背景・罫線・文字・アクセント

| 名前 | 値 | 用途 |
|---|---|---|
| `--bg` | `#0a0a0c` | アプリ全体 |
| `--surface` | `#111116` | サイドバー、カード、入力 |
| `--raised` | `#17171d` | ポップオーバー、メニュー |
| `--line` | `rgba(255,255,255,.07)` | 通常の罫線 |
| `--line-strong` | `rgba(255,255,255,.12)` | 入力の縁 |
| `--border-strong` | `rgba(255,255,255,.12)` | ポップオーバーの輪郭 |
| `--text-primary` | `#ededf2` | 本文・見出し |
| `--text-secondary` | `#a4a4b3` | 12px の補助テキスト全般 |
| `--text-tertiary` | `#7c7c8c` | アイコン・11px のラベル |
| `--brand` | `#7c6cff` | 選択・フォーカス・主要操作の 1 色 |

**アクセントは紫 1 色だけ**です。選択、フォーカスリング、適用中のフィルタバッジ、
主要操作（ルート追加）以外では使いません。ルート識別のドットは無彩色にしました
（以前の violet / cyan / magenta / amber / emerald の循環は廃止）。

ポップオーバーは `border: 1px solid var(--border-strong)` と
`box-shadow: 0 12px 32px rgba(0,0,0,.55)` でグリッドから浮かせます。

#### コントラスト（WCAG 2.1・実測）

headless Chrome（1280×800）で実際の computed style を取得し、親をたどって
実効背景色を合成して計測しました。12px の補助テキストはすべて 4.5:1 以上
（通常状態は 7:1 以上）です。

| 対象 | 文字色 | 背景色 | 比 | 判定 |
|---|---|---|---|---|
| カードのメタ（`1 ファイル・5.0 GB`） | `#a4a4b3` | `#111116` | 7.65:1 | AAA |
| カードのメタ（ホバー） | `#a4a4b3` | `#17171d` | 7.26:1 | AAA |
| カードのメタ（選択・紫 10% 混合） | `#a4a4b3` | `#1c1a2d` | 6.91:1 | AAA |
| カードの日付（`2026/11/25`） | `#a4a4b3` | `#111116` | 7.65:1 | AAA |
| サイドバーの説明文 | `#a4a4b3` | `#111116` | 7.65:1 | AAA |
| ツールバーの件数（`24 作品`） | `#a4a4b3` | `#0a0a0c` | 8.04:1 | AAA |
| フィルタ内の補助文 | `#a4a4b3` | `#17171d` | 7.26:1 | AAA |
| `サムネ非表示（リスト）` | `#a4a4b3` | `#0a0a0c` | 8.04:1 | AAA |
| 本文（primary） | `#ededf2` | `#111116` | 16.13:1 | AAA |
| 選択チップ（塗り） | `#0a0a0c` | `#7c6cff` | 5.13:1 | AA |
| アクセント文字 | `#7c6cff` | `#0a0a0c` | 5.13:1 | AA |

参考: `#7c7c8c` は `--bg` 上で 4.82:1、`--surface` 上で 4.59:1 ですが、
`--raised` 上では 4.35:1 のため、ポップオーバー内の文字には使いません。

#108（表示用フォント / アイコン化）でも色は変更していないため、上の実測値を維持して
います。再測した主要値: primary `#ededf2` on `--surface` **16.13:1**、secondary
`#a4a4b3` on `--surface` **7.65:1**、tertiary `#7c7c8c` on `--bg` **4.82:1**、
brand `#7c6cff` on `--bg` **5.13:1**（いずれも 4.5:1 以上）。

### 文字

| 名前 | 値 | 用途 |
|---|---|---|
| `--font-size-11` | 11px | フィルタ節ラベル（uppercase + letter-spacing .08em）のみ |
| `--font-size-12` | 12px | 統計・補助情報・チップ |
| `--font-size-13` | 13px | 本文・ボタン・カードタイトル |
| `--font-size-15` | 15px | 強調本文 |
| `--font-size-21` | 21px | 画面タイトル |
| `--font-size-32` | 32px | 作品詳細の題名（#99） |

行間は本文 `1.5`、見出し `1.3`。**12px 未満はフィルタ節の 11px ラベルだけ**にし、
サイドバーの節見出し・説明文を含む補助テキストは 12px 以上にしました。

**表示用フォント（#108）**: 21px 以上の見出し（アプリ名 21px・作品詳細の題名 32px）にだけ
`--font-display: "Segoe UI Variable Display", "Segoe UI", sans-serif` を使い、
`letter-spacing: -0.02em` で締めます。Windows 標準のフォントだけで、追加アセットはありません。

### 動き・フォーカス

| 名前 | 値 |
|---|---|
| `--duration-fast` | 160ms |
| `--ease-standard` | `cubic-bezier(.2,.7,.3,1)` |
| `--focus-width` | 2px |
| `--focus-offset` | 2px |

`prefers-reduced-motion: reduce` では animation / transition を 0.01ms に落とし、
スクロールも即時にします。フォーカスは `outline: 2px solid var(--brand)` +
`outline-offset: 2px` で統一しています。

### 状態・空状態・読み込み（#100）

空状態は `src/library/EmptyState.tsx` の 1 つの形に集約します。**控えめなアイコン
（`--text-tertiary`）+ 短い説明 + 次の行動 1 つ**だけを置き、作品（サムネイル）より
目立たせません。

| 状態 | 場所 | 次の行動 |
|---|---|---|
| ルートが無い | サイドバー | ルートを追加 |
| スマートフォルダが無い | サイドバー | 条件を絞り込む（検索欄へフォーカス） |
| 検索結果が 0 件 | メイン | 条件をクリア |
| サムネイル未生成 | メイン上部の notice | サムネイルを生成 |

- サムネイル未生成は、サムネ表示中なのに読み込んだ作品の `cover_thumb` がすべて
  `null` のときだけ出す（生成が進めば自動で消える）
- 読み込み中は**カード形状（4:3 のカバー + メタ 2 行）を保つスケルトン**を
  **3 列 × 2 行**で出す。表示は `useDelayedVisible` により **200ms 経過後**から。
  200ms 未満で終わる読み込みでは一度も出さない（ちらつき防止）
- 空状態の確認用に `?bench=N&empty=roots|smart|search|thumbs` を用意した
  （ベンチ時だけデータを差し替える。通常起動には影響しない）

### フォーカスとキーボード（#100）

- 操作要素の `:focus-visible` は **2px / offset 2** のブランド色リング。
  `outline-none` などのユーティリティに負けないよう、ルールは `@layer base` の外
  （unlayered）に置く
- 一覧 → 詳細 → 戻るはキーボードだけで完結する:
  `Tab` / `j` `k` でフォーカス → `Enter` で詳細 → `Esc` または `Alt+←` で戻る
- アイコンボタンは `aria-label` を必須にする（ツールチップは補助）。ダイアログの
  `×` も「閉じる」と読み上げる
- `prefers-reduced-motion: reduce` ではホバー / 選択 / ダイアログの動きを止める

### ダイアログ（#100）

設定・`?` ヘルプ・重複整理・比較ビューのヘッダー / 余白 / 文字サイズを共通化:

- ダイアログ本体: `--radius-panel` / `padding 24` / `gap 16` /
  `--border-strong` の 1px 罫線 + `--shadow-panel`
- 題名 15px / 600、説明 12px `--text-secondary`
- 開閉は 160ms のフェード + **0.98 → 1 の拡大**（`zoom-in-98` / `zoom-out-98`）
- 比較ビューの上部バーも 56px / 24px 余白 / 15px 題名に揃える（機能は変更しない）

### ヘッダー（56px・1 段）

- 左: ブランドマーク（右上に **2px のアクセントドット**）+ 「ライブラリ」21px / 600
  （`--font-display` / `-0.02em`）
- 統計: 12px tabular の 1 行。`作品 24 · ファイル 96 · サイズ 1.2 GB · 最終走査 2026-11-27`。
  走査していないときは「最終走査 未走査」と出す
- 右: 32px のアイコンボタン（**ツールチップ必須**）+ 主要操作 1 つだけ塗り
  - サムネイル表示（`ThumbnailToggle variant="compact"`）/ 重複整理 / シールド設定 /
    再読み込み / ルート管理 / 設定
  - 「ルート」だけが塗り（紫 + 黒文字）
  - 設定は以前の右下固定ピルを廃止し、ヘッダーへ移した（コンテンツに被らない）
- ウィンドウ幅 1280px でも折り返さない（`h-14` 固定・`flex-nowrap`）

### ツールバー（48px・1 段）

- 検索: `flex` で 320〜420px。`/` でフォーカス、`Escape` でクリア
- **フィルタ**ボタン: 適用中の条件数をバッジ表示。ポップオーバーに
  種類 / ルート / タグ / 評価 / お気に入り / 生成情報も検索
- **並び**メニュー: 更新日・追加日・名前・サイズ・ファイル数（+ 最近見た / よく見る）
- 昇順 / 降順は**アイコントグル 1 つ**（メニューとは別）
- フィルタの選択は**紫の塗り + 黒文字**で統一（白い選択は使わない）。種類・ルート・評価・
  お気に入り・生成情報のどれも同じ見た目にする
- ポップオーバーは `--border-strong` の 1px 罫線 + `0 12px 32px rgba(0,0,0,.55)` の影
- 右端は**件数 + サムネトグル + 表示切替**のクラスタとして揃える（件数だけが中央に浮かない）
- サムネトグルは `Eye` / `EyeOff` + 「サムネ」の 12px。`aria-pressed` は
  「表示中か」で、`title` に `Ctrl+Shift+H` を出す（#120）
- 適用中のフィルタだけを、ツールバーの下に**削除可能なチップ**で表示

### 戻ったときの絞り込み復元（#120）

`LibraryView` は作品詳細へ移動するとアンマウントされるため、絞り込みは画面ローカルに
持たず、離脱時に `LibrarySnapshot.filters` へ写します。

- 対象: ルート / 検索語 / 種類 / タグ / 最低評価 / お気に入り / 生成情報も検索 /
  並び順 / 昇順・降順 / ファイルモードのルート
- 初期値は `initialFilters` として `LibraryView` に渡し、`useState` の初期化に使う。
  「すべて」「空検索」を選んだ場合はその新しい値が写るため、古い条件は復活しない
- サムネトグルは作品 / ファイル / タイムラインの全ツールバー右端に置き、
  ヘッダーの目アイコン・作品詳細の「サムネ表示」と同じ状態を共有する
- 1280×800（サイドバー 240px 込み）でも 1 段のまま折り返さない

### サムネイル表示の共通 UI と作品単位の一時表示（#121）

サムネイルの表示切替は `ThumbnailToggle` 1 つに寄せます。

| variant | 場所 | 見た目 |
|---|---|---|
| `compact` | ヘッダー | 32px アイコンのみ（ツールチップ `Ctrl+Shift+H`） |
| `labeled` | ライブラリ / ファイル / タイムライン / 作品詳細のツールバー右端 | `Eye` / `EyeOff` + 「サムネ」12px |

- `aria-pressed` は「サムネイルを表示しているか」。非表示時は `EyeOff`
- ヘッダー / 全ツールバー / 作品詳細が同じ `useThumbnailVisible` を共有する
- 全体非表示中は作品カード右上（チェックボックスの左隣・8px 間隔）に目アイコンを出し、
  「この作品のサムネイルを表示 / 隠す」でその作品だけカバー（4 枚揃えばモザイク）を表示する
- ファイルの「このファイルだけ表示 / 隠す」と同じく、全体トグルを切り替えると
  個別状態はリセットされ、永続化しない
- タイムラインは `WorkCard` を再利用するため、同じ位置・同じ挙動になる
- **目アイコンは hover / focus のときだけ出す**（#5）。普段は `opacity: 0` +
  `pointer-events: none` で、カードの `group-hover` / `group-focus-within` と
  ボタン自身の `focus-visible` で表示する。キーボードの Tab でも見える
- タッチ環境（`@media (hover: none)`、`index.css`）だけは常時表示に戻す。
  チェックボックスの hover 表示は変更しない

### サイドバー（240px）

- 節見出し: 12px / letter-spacing `.08em` / secondary
- 行: 32px（`h-8`）。件数は右寄せ tabular（secondary）
- 「すべて」→ 各ルート → スマートフォルダの順
- ルートが無いときは **オンボーディング 1 ブロックだけ**（説明は 1 行 + 「ルートを追加」）。
  スマートフォルダの節・空状態はルートがある場合だけ出す
- スマートフォルダが無いときの説明も 1 行（「絞り込みを保存できます。」）
- 行の「…」で再スキャン / 有効・無効 / 削除（従来どおり）
- 作品カードのドラッグ&ドロップ先としても機能（#57）

### 作品カードとグリッド（#98）

カードの寸法は `src/library/gridMetrics.ts` が正です。`WorkGrid` は仮想スクロールの
行送りに、`TimelineView` は日別セクションの行送りに、`WorkCard` はカバー高さに同じ値を
使います。

#### カード

- **カバー**: アスペクト比 **4:3 固定**、画像は `object-fit: cover`、角丸 `--radius-card`（12px）。
  サムネイル非表示が既定なので、カバーが無い状態が基本形になる
- **種類バッジ**: 写真の**左上**に **14px のアイコンのみ**（白 60% + 落ち影）。
  ピル・背景・文字は使いません。画像なしのときは従来どおり **20px のアイコン**。
  どちらもツールチップ / `aria-label` で「画像 / 動画 / 混在」を出す
- **メタは 2 行だけ**:
  1. 題名 15px / 600（1 行、`truncate`）
  2. `N ファイル · サイズ · 日付` 12px `--text-secondary` / tabular
  - ルート名は余白を優先してカードに出さず、ツールチップと `aria-label` に含める
- **ホバー**: 背景を 1 段明るく（`--surface` → `--raised`）、枠を `--line-strong` に。
  開く操作（右上の矢印）と選択チェックを **160ms** でフェードインする
- **フォーカス**: 追加の背景・枠は変えず、2px のリングだけ（`--brand`）
- **選択**: チェックボックスに加えて、**アクセント 2px の内側リング + 10% の背景ティント**。
  チェックが出ていなくても選択中と分かる
- **壊さない**: ホバー動画プレビュー（#46）、2×2 モザイク（#21）、メタバッジ、
  ドラッグ&ドロップ（#57）、`j` / `k` のフォーカス移動（#71）

#### プレースホルダ（タイポグラフィック・カバー）

画像なしのカードは「暗い空箱」にせず、**タイトルから生成した表紙**にする
（Linear / Arc のプロジェクトタイルのような扱い）。同じ作品は常に同じ見た目になる。

- **背景**: タイトルのハッシュ（FNV-1a）から色相 `H` を決め、
  `linear-gradient(155deg, hsl(H 60% 60% / 8%), transparent 60%)` を `--surface` に敷く。
  彩度 60% / 明度 60% は**全作品で固定**し、色相だけを変える
- **中央**: タイトルの先頭文字。日本語は **1 文字**、英数字は **2 文字（大文字）**。
  56〜72px（カバー高さ × 0.36）/ 650 / `rgba(255,255,255,.07)`。少しだけ左下へ寄せる
- **面**: `inset 0 0 0 1px rgba(255,255,255,.04)` の内側ボーダー（ノイズ画像は使わない）
- **種類バッジ**: 画像なしではアイコンのみ（20px + ツールチップ）。3 種類（画像 / 動画 /
  混在）で大きさ・色・位置を揃える

計算は `src/library/placeholder.ts`、見た目は `src/index.css` の `.work-placeholder` /
`.work-placeholder-initials`。

| タイトル例 | 文字 | 色相 |
|---|---|---|
| `静かな海` | `静` | タイトルごとに 0〜359 |
| `ベンチ作品 00001` | `ベ` | 同上 |
| `Bench Work 00001` | `BE` | 同上 |
| `2026 summer` | `20` | 同上 |

#### グリッド

- 列数は **3〜6**。外側余白 24（`--space-6`）、間隔 16（`--space-4`）
- 内側の幅（外側余白を引いた値）で決める:
  - `>= 1560` → 6 列
  - `>= 1240` → 5 列
  - `>= 880` → 4 列
  - それ未満 → 3 列
- **1280×800**（サイドバー 240px を引いた ≒ 1040px）で **4 列**、
  **1920×1080**（同 ≒ 1680px）で **6 列**。外側余白 24 / 間隔 16 はそのまま
  （#108 で 1920×1080 のスクリーンショットを再確認）
- カード高さ = カバー（幅 × 3/4）+ メタ 66px。幅が変わったら仮想スクロールを測り直す

### 作品詳細（#99）

Phase 3。作品 1 件を開いた画面も同じトークンで組み直しました。作品そのもの（サムネイル）が
主役で、操作系は右上と `⋯` に集約します。

#### ヘッダ（3 層）

| 層 | 内容 |
|---|---|
| 1 | 左上に戻る（`←` 28×28・ツールチップ `ライブラリへ戻る（Esc）`）/ 題名 **32px / 650**（1 行、必要なら 2 行まで）/ 右上に **開く**（塗り）と **フォルダ**（outline）の 2 つだけ |
| 2 | メタ 1 行: `24 ファイル · 100.7 MB · 2026/11/25 · お気に入り · 開封 1 回 · ルート名`（12px secondary・tabular）。#108 で右側の小チップをここへ統合。タグだけ現行のチップを残す |

- 題名の折り返しは 2 行まで（`line-clamp-2`）。それ以上は省略し、`title` で全文
- 削除・選択ファイルの表示などは右上の `⋯` メニューへ（`role="menu"`・Escape / 外側クリックで閉じる）
- 選択バーはヘッダの下、ツールバーの上。件数・合計サイズと `比較` / `削除` / `選択解除`

#### ツールバー（48px・1 段）

- 種類（すべて / 動画 / 画像）は**セグメント**（`aria-pressed` は常に 1 つ）
- 並びは**メニュー**、昇順 / 降順は**アイコントグル 1 つ**（キーごとの既定へ戻す）
- サムネイルの大きさ（小 / 中 / 大）は右寄せのセグメント 1 つ
- 右端は **`N ファイル`** と **`サムネ表示`**（表示 / 非表示トグル）の 12px secondary だけ
- スクロール領域の外に置くので、一覧をスクロールしても常に 1 段で残る

#### ファイルカード（#98 の規則）

- サムネイルは **4:3**（列幅から高さを計算し、仮想スクロールの行高と一致させる）
- 角丸 **12px**（`--radius-card`）、罫線 `--line`、ホバーで 1px 持ち上げ
- 名前は **1 行**で省略、メタは **2 行**（`5.3 MB · 2026/11/25` / `動画 · 0:42`）
- 種類バッジはメタ 2 行目へ移し、サムネイル上は長さ・`meta`・続きバッジだけにした

#### ライトボックス

- 余白は 16 / 24、文字は 12 / 13px、罫線は `--line` 相当の白 10%
- ボタン位置・キー操作・既定ミュート（音量 0）・自動再生は変更しない
- **`?` でショートカット一覧をライトボックスの上に開ける**（#5）。ヘルプの
  オーバーレイは `z-120`、本体は `z-121` で、ライトボックス（`z-80`）と
  ComfyUI の確認（`z-95`）より前面に置く
- `Esc` の優先順位は **ヘルプ → ライトボックス → 作品詳細**。ヘルプ表示中は
  ライトボックスのキー操作（再生・シーク・移動）もしない。ヘルプを閉じても
  下のスクロール位置・選択は保持する

## 機能の到達性

Phase 1 で削った操作はありません。ヘッダーのテキストボタンはアイコン + ツールチップへ、
ツールバーのチップ列はフィルタポップオーバー + 適用中チップへ移しました。
キーボード操作は変更していません。

| キー | 動作 |
|---|---|
| `Ctrl+1..9` | ルート絞り込み（`Ctrl+0` ですべて） |
| `Alt+1..3` | 作品 / ファイル / タイムライン |
| `Ctrl+Shift+H` | サムネ表示トグル |
| `Ctrl+Shift+T` | タイムライン |
| `/` | 検索フォーカス |
| `Ctrl+A` / `Esc` | 全選択 / 選択解除 |
| `Delete` / `Shift+Delete` | ゴミ箱へ / 完全削除 |
| `?` | ショートカット一覧 |
